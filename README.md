# SGNLCHAIN showcase
Responsive, buildless music showcase. Serve `dist/` with any static host. No installation or build step required.

Includes a tunable canvas signal, pause/reduced-motion support, artist filters, release artwork, and verified outbound music links. Audio is never autoplayed; release links open the original music platforms.

Content sources: https://linktr.ee/sgnlchain and linked Traxsource release pages, accessed October 6, 2026. This is a showcase concept; brand assets and music artwork belong to their respective owners. Selected releases are curated, not an automatically synchronized latest catalogue.

GitHub Pages: publish the contents of `dist/` using the included Actions workflow. Enable Pages with GitHub Actions in repository settings. No secrets required.
